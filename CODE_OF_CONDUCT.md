# Code de conduite

SuperMenu adopte le
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/)
comme code de conduite. Ce texte fait référence ; il n’est pas recopié ici.

Il s’applique à tous les espaces du projet (issues, pull requests, revues de
code, commentaires) ainsi qu’aux personnes qui représentent le projet ailleurs.

## En bref

- Restez respectueux et bienveillant, y compris en cas de désaccord.
- Critiquez le code et les idées, jamais les personnes.
- Accueillez les questions des débutants et les points de vue différents.
- Le harcèlement, les propos discriminatoires, les attaques personnelles et la
  publication d’informations privées d’autrui sans son accord ne sont pas
  tolérés.

## Signaler un comportement

Contactez le mainteneur, [@lfpoulain](https://github.com/lfpoulain), via les
moyens de contact indiqués sur son profil GitHub. Pour un contenu publié sur
GitHub, vous pouvez aussi utiliser la fonction **Report content** de GitHub.

Chaque signalement est examiné avec discrétion, et l’identité de la personne
qui signale est protégée.

## Application

Le mainteneur peut modifier ou supprimer un contenu, verrouiller une
discussion, ou exclure temporairement ou définitivement une personne du
projet, selon les lignes directrices d’application du Contributor Covenant.
